# Homebrew Tap for Podiom

This tap installs Podiom from the official GitHub release artifacts.

```sh
brew install Podiom/podiom/podiom
```

After installation, start the daemon with `podiomd` and use the CLI with `podiom`.

For the main project, see [Podiom/Podiom](https://github.com/Podiom/Podiom).
